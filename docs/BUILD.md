# iCSM 自行编译与数据导入

本套件只用于 iPhone / iPad。原生 Source 游戏模块、SDL 和 Metal 后端由本地源码编译；套件不含已经编译的游戏框架、作者签名、账户或设备配置。V8、字体/视频等第三方静态依赖以及构建时生成的协议头文件已提供。游戏地图、材质、皮肤预览与离线着色器另在 `iCSM-v2.zip` 中。

Windows 或仅通过 GitHub 生成 **IPA 与配套数据包**，请使用新工作流 **Build iCSM IPA + Data**，见[完整指南](DATA_BUILD.md#简体中文)。新流程从真实 MSL 编译着色器，使用 GitHub 上的资源输入打包；须导入同次 Release 的数据，不能直接沿用旧 iCloud 包。

## 1. 在 Mac 上编译并安装

需要 macOS、带 iPhoneOS 27.x SDK 的 Xcode、Python 3 和网络（首次安装固定版本的 CMake / Ninja）。当前应用最低系统为 iOS / iPadOS 27.0。Windows 用于导入数据，不能直接运行 Xcode 编译。

在 Xcode → Settings → Accounts 登录自己的 Apple 账户。连接、解锁设备，打开开发者模式。在终端进入本文件所在目录：

```sh
./icsm doctor
./icsm setup --team 你的TeamID --bundle-id com.你的名字.icsm --device 你的设备ID
./icsm build
./icsm install
```

编译过程包括原生引擎模块、Metal / SDL 模块和应用，然后用你的证书签名，产出 `Build/iCSM.ipa`。也可以使用 `./icsm modules` 重建原生模块、`./icsm app` 仅重建应用。完整源码构建需要较长时间和较多磁盘空间。更新应用请保留原 TeamID / Bundle ID，覆盖安装，避免卸载导致游戏数据、库存、设置和触摸布局丢失。

签名应用的中间目录位于 `~/Library/Caches/iCSM-build/`，以避开 iCloud 文稿 / 桌面目录附加的 Finder 元数据；原生模块和最终 IPA 仍保存在本套件的 `Build/` 中。

IPA 中包含 ARM64 iOS 模块，不包含 macOS 游戏、不依赖 Rosetta 或运行时翻译。免费账户的签名有效期通常为 7 天，需要重新签名安装；以 Xcode 和设备实际返回的签名限制为准。首次安装若系统要求信任开发者证书，请在设置中完成。

## 2. 导入数据包

**直接在 iPhone / iPad 导入（Build 149 起）**：先将配套 ZIP 下载到系统“文件”App，然后打开 iCSM，在初始页左上角点击 **选择数据包 ZIP**，从“我的 iPhone / iPad”或 iCloud Drive 选择文件。无需解压，也无需手动移动到 iCSM 目录；重复下载产生的文件名后缀不影响选择导入。应用仍严格核对配套清单，不接受其他版本或任意 ZIP。云端文件需要先下载；读取／解包时请保持应用在前台。此方式保留选中的原 ZIP，成功进入大厅后可自行删除原 ZIP 释放空间。

**从 Mac / Windows 文件共享导入**：

安装应用后可以先打开，会显示导入说明。将提供的文件保留为精确名称 `iCSM-v2.zip`，无需在电脑上解包，也无需复制到某个隐藏目录：

- **Mac**：Finder → 连接的设备 → 文件 → iCSM，将 `iCSM-v2.zip` 拖到 iCSM。
- **Windows**：Apple Devices → 连接的设备 → 文件 → iCSM → 添加文件，选中 `iCSM-v2.zip`。

复制时让游戏停留在导入页。**等待电脑明确完成复制**，然后点击游戏中的“检查并导入”。不要在游戏对局运行期间替换数据。也可以通过 iOS“文件”App 将同名数据包移入“我的 iPhone / iPad → iCSM”。

完整数据约 19.65 GB，首次导入同时占用压缩包、解压后的数据和少量缓存；开始复制前建议至少预留 **35 GB**。应用会核验所需剩余空间。所有文件通过 SHA-256、ZIP CRC 与路径校验后才逐个提交，损坏或中断会显示原因；再次导入时保留已经验证的文件。配套清单固定在签名的应用中，请使用本版本对应的数据包。

使用“检查并导入”成功后自动删除应用目录中的导入用压缩包；通过“选择数据包 ZIP”导入时保留原 ZIP。资源保存在游戏目录中；**不要删除 `game-assets`、`runtime-i5`**。电脑文件共享可见的 `runtime-i5` 是个人配置和存档，不属于需要再次导入的数据。

苹果操作说明：[Mac Finder](https://support.apple.com/en-us/119585)、[Windows Apple Devices](https://support.apple.com/en-us/120402)。编译与资源分离、完成记录和恢复流程参考 [brolnickij/emu](https://github.com/brolnickij/emu)。

## 3. 首次启动

游戏依次显示资源校验 / 导入、首次 Metal 着色器准备、大厅加载。数据包提供 7906 个已离线编译的 iOS Metal 着色器库；首次启动会在设备上实际加载并验证，之后复用持久记录。系统清理临时缓存时可以从已导入的数据恢复，无需重新下载整包。

着色器库和渲染管线不同：地图、材质和皮肤仍可能首次触发新的管线组合。游戏保留现有的设备专用管线缓存与记录机制，不向另一型号复制 GPU 管线二进制，也不承诺首次进入任意地图都完全没有编译。

Build 149 全新安装默认使用中档，也就是 iPhone 实机优化方案：约 170 万场景像素，按屏幕比例自适应（iPhone 17 Pro Max 为 1920×884，4:3 iPad 为 1504×1128），100% 场景比例，120 帧上限，插帧和空间超分默认关闭，地图基础贴图保留、远处阴影覆盖 65%、地图普通凹凸光照简化，4×纹理过滤，皮肤光影和贴图默认最高。帧率、插帧、动态模糊与武器画质可单独选择，其余由极低／低／中／高预设管理。升级保留已有档位和个人配置，不会反复覆盖。全屏锁定继续保留。

玩家头像使用 CSGO 默认头像，初始昵称为 `icsmer`。点击大厅底部中央的昵称栏，会自动弹出系统键盘；输入后选择“保存”即可修改，重启和升级后保留。支持中文，昵称不能为空，UTF-8 长度不超过 127 字节。

每次从头启动，资源和大厅准备完成后会先显示公告；公告在前台完整显示至少 20 秒后自动进入大厅，无法跳过，后台时间不计入倒计时。

项目已实际验证的设备为 iPhone 17 Pro Max 与 M5 iPad Pro；其他型号的完整兼容性、内存占用和帧率尚未实测。120 Hz 显示、插帧支持和运行性能以实际设备为准。

## 4. 文件与隐私

`config.local.json`、`Build/`、签名 IPA 都是用户本机产物，不应放入公开源码包。应用不会要求 Apple 密码，不会从网络下载游戏资源。导入只处理固定资源白名单，不改写库存、触摸布局和个人昵称。卸载应用会移除整个应用数据，请先备份。

保留各依赖原有版权与许可文本。资源包只包含本项目已使用的游戏资源与修改，使用和分发范围由资源的相应权利约定决定。

## 5. 导出报错日志

初始加载／导入页右上角始终提供 **导出报错日志**，未导入数据、正在导入或导入失败时均可使用。进入大厅后，也可打开 **设置 → 游戏设置 → 游戏 → 报错日志 → 导出报错日志**。通过系统分享窗口保存到“文件”或发送 ZIP。导出的 ZIP 同时保存在应用的 `Documents/Diagnostics`，可通过 Finder / Apple Devices 文件共享取出；最多保留三份导出包。

导入诊断 `import-diagnostics.json` 记录本次导入的阶段、进度、数据包名称与大小、剩余及所需空间、缺失文件数量和具体失败文件。可区分未找到数据包、文件名不符、ZIP 损坏、CRC／SHA-256 校验失败、空间不足、文件读写失败，以及着色器加载错误；失败详情保留底层错误码。

应用保留本次和之前两次启动的运行、控制台与状态记录；闪退后重新打开，再立即导出。每份文本日志只导出最后 2 MiB，打包在后台完成。包内包含应用版本、系统版本、机型、Metal 和画面状态、加载失败详情；着色器错误保留文件名与底层 Metal 错误码。不会导出数据包、配置、命令文件或存档，常见密码命令会过滤；运行日志仍可能包含玩家和服务器信息，分享前可以检查。

苹果 [MetricKit](https://developer.apple.com/documentation/metrickit) 提供的崩溃及其他诊断会保存并加入导出包。系统未交付诊断时，ZIP 中只有运行记录，不能当作完整崩溃堆栈；需要时同时提供“设置 → 隐私与安全性 → 分析与改进 → 分析数据”中的应用 `.ips` 报告。
