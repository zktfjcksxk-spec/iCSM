iCSM Ubuntu 私人服公网连接修复

本补丁对应 iCSM-Server.tar.zst 中的 Linux x86_64 引擎。
修复无 Steam 专用服务端的挑战包将“没有大厅”写成 -1 的问题。
旧客户端因此进入 GC / 局域网检查，公网连接显示“限制客户端只能从内部
局域网连接”。修正版将无大厅 ID 正确写为 0，保留原版协议版本、挑战值
和房间密码检查。客户端、游戏数据、地图轮换及库存功能无需替换。
无需 Steam 游戏服务器令牌，也无需把 sv_lan 改为 0。

Ubuntu 更新步骤（先停止原服务端）：
1. 在原服务端控制台输入 quit，确认它已经退出。
2. 在上传补丁的目录解压：
   tar -xzf iCSM-Server-PublicFix.tar.gz
3. 将下面的 /path/iCSM-Ubuntu-x86_64 换成你现有服务端目录：
   python3 iCSM-Server-PublicFix/apply_update.py /path/iCSM-Ubuntu-x86_64 --check
   python3 iCSM-Server-PublicFix/apply_update.py /path/iCSM-Ubuntu-x86_64
4. 回到原服务端目录：
   cd /path/iCSM-Ubuntu-x86_64
   ./start-server.sh

补丁仅替换 bin/libengine.so、记录校验信息和添加本说明。
旧引擎保存在服务端目录内的 direct-connect-backup-日期时间 文件夹。
server-settings.json、csgo/cfg、地图和玩家库存不会被改写。

手机 / iPad 游戏控制台：
   password "你的房间密码"
   connect 服务器公网IPv4:游戏端口
例如端口仍为默认值时，用 connect 服务器公网IPv4:27015。
云服务器安全组与 Ubuntu 防火墙需允许该 UDP 游戏端口。
启动参数仍使用包内的 -insecure -nomaster，无 Steam/GC/VAC 服务。

验证范围：x86_64 Linux 引擎交叉编译及 ELF 动态依赖检查通过；以原始
客户端连接函数复现旧公网拒绝，并验证新握手在公网及局域网地址下可继续
发送连接包、无 GC 调用。朋友远程服务器的真实入局尚需部署后验证。
